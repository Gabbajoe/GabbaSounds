# GabbaSounds 1.0.0

First CurseForge release, bringing together the wand and hunter packs with the expanded mage library.

- Added spoken recordings for 15 frost and fire mage spells, covering all 83 Classic ranks.
- Added cast, channel-start and activation sounds, alongside hit and critical-hit reactions for damaging spells.
- Added shared miss, resist, absorb and partial-hit reactions.
- Added one result reaction per supported area-effect application; Blizzard reacts once after its first damage burst.
- Added a mage-only pack and individual spell selections.
- Included 179 spoken clips and 126 synthetic wand sounds.
- Included automatic wand, bow/crossbow and gun selection, randomized playback and in-game previews.
- Included optional original-sound muting and a spoken-only mode. Muting affects shared native sound files globally.
- Included minimap controls and per-character settings.

Target client: WoW Classic Era / Hardcore 1.15.9, Interface 11509. No required addon dependencies.
